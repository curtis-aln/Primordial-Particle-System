# Heatmap grid section
- Trail amount
- LUT_SIZE
- Peak EMA smoothing (m_peak_ema) — controls how fast the brightness adapts to density changes. Slider 0–1.
- Fixed peak override (fixed_peak param in upload()) — lets you pin the scale instead of auto-ranging. A checkbox to toggle between auto/fixed, plus an int input when fixed.
- Sprite alpha (alpha param in draw()) — overall heatmap opacity. Already a uint8, just a 0–255 slider.
- Downsample factor — passed at construction, so you'd need a rebuild, but an int combo (1×, 2×, 4×, 8×) is very useful for perf tuning.

Gradient editor (m_stops via set_gradient()):
This is the richest one — each GradientStop has a t position and an RGBA colour. You could expose a small table: one row per stop with a ImGui::ColorEdit4 and a ImGui::DragFloat for the position t. Add/remove stop buttons. Calls set_gradient() on any change.
Derived from scatter logic:
The bilinear splat is always weight 1 per point — you could expose a point weight/intensity multiplier so you can boost density without adding more points.
